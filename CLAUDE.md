# Noman.me Project Guide

## Tech Stack
- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS (Minimalist B&W)
- Package Manager: pnpm

## Coding Rules
- Use Functional Components and Arrow Functions.
- Use 'lucide-react' for icons.
- Prefer server components over client components unless interactivity is needed.
- Follow a minimalist design: Use Zinc colors from Tailwind (e.g., zinc-900 for dark, white for light).

## Essential Commands
- Install: `pnpm install`
- Dev: `pnpm dev`
- Build: `pnpm build`
